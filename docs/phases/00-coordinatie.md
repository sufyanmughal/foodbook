# Fase 0 — Coördinatie (doorlopend)

Uren: **15** (verspreid over het hele project, niet in één blok)
Afhankelijk van: — (loopt parallel aan alle andere fasen)
Terug naar: [PLAN.md](../PLAN.md) · [ARCHITECTURE.md](../ARCHITECTURE.md)

## Doel

De niet-code-tijd die elk project heeft: afstemmen met de klant, scope bewaken, korte statusupdates, en beslissingen vastleggen zodat ze niet later opnieuw besproken hoeven worden.

## Acties

1. Kick-off: v1-scope schriftelijk bevestigen met klant (dit bouwplan + ARCHITECTURE.md als bijlage).
2. Bij elke faseovergang: kort statusbericht naar klant (wat is klaar, wat is de volgende fase).
3. Beslissingen die tijdens de bouw genomen worden (bijv. een kleine scope-interpretatie) vastleggen in [BESLISSINGEN.md](../BESLISSINGEN.md) — niet mondeling laten hangen.
4. Eén tussentijdse demo/review-moment inplannen (bijv. na Fase 6, wanneer de volledige keten voor het eerst end-to-end werkt) — geen goedkeuring vereist om door te gaan, maar wel zichtbaarheid voor de klant.
5. Tweede kort demo-moment na Fase 7 (Offline & Synchronisatie), specifiek om het offline-scenario aan de klant te laten zien — dit is de nieuwe, meest onzichtbare fase en verdient een concrete demonstratie in plaats van alleen een statusbericht.
6. Eindoplevering: gestructureerde walkthrough + overdracht, inclusief de acceptatietest (zie [Fase 11](./11-testen-oplevering.md)).

## Klaar is klaar

- [ ] Scope schriftelijk bevestigd vóór start Fase 1
- [ ] Beslissingenlog bijgehouden gedurende het project
- [ ] Klant heeft minstens 1 tussentijdse demo gezien vóór eindoplevering
